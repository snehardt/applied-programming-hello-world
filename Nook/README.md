# Nook

A whiteboard app for organizing ideas and working with other people. You can add notes, draw, and save your boards.

## Instructions for Build and Use

Steps taken to build the software:

1. Make a whiteboard space with notes, shapes, and drawing tools.
2. Add a database to save boards and accounts.
3. Add accounts, sharing links, and live updates so people can work together.

Instructions for using the software:

1. Create a board or open a shared board.
2. Add notes, drawings, tasks, or files.
3. Sign in to save your board permanently and invite other people.
